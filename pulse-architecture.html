03What the model decides, and what it never touches

  THE MODEL DECIDES                      CODE DECIDES
  ─────────────────────────────────      ──────────────────────────────────────
  which intent a question is             which card renders the result
  what SQL computes the answer           whether that SQL is allowed to run
  how to phrase the sentences            every number in a narration (pre-formatted)
  which follow-ups are worth offering    the period maths (IST calendar days)
                                         the contribution ranking and baseline
                                         the ladder arithmetic
                                         which entity a name resolves to
                                         when two answers disagree

The rule the whole design turns on: the model decides what to compute, never how to show it. Every presentation decision is a function of data that exists after the query ran, and those functions are testable to 100% — the shape chooser is 130/130 on correct rows.

05Deliberately absent

Not builtWhy
Repair of a wrong-but-valid answerNet 0 across three runs. The errors are systematic — a second attempt reproduces the same misunderstanding
3-sample votingIdentical mean, ever-ok and never-ok set at 3× tokens and 3.6× latency
LLM inspection as a gate9–27% catch, no net gain; the measurement was itself confounded by my prompt truncation
Deterministic invariants as a user-facing flagPrecision 13–20% against a 22% base rate — anti-informative, a flag made the answer look less likely wrong
FK edges in the schema blockLost 3/3 reps, cost 583 tok/q. Silently absent for months and nothing noticed
Patient-level outputBlocked by design at three layers: role grants, validator, and an explicit refusal that points at Money → Bills

The one verification that survived: write the money query twice, compare the results. 50% precision against a 22% base rate, 40% recall, 7% false alarms. It marks the answer. It never replaces the number, because it cannot tell which of the two is right.
