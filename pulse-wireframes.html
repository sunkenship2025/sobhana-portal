Thinking — and what the orb does

Idle
Slow drift, ±1px. Alive, not busy.
Thinking
Scale-pulse at ~1.1s. Answers take ~2s; this covers it without a spinner.
1 thing
Amber dot. The diagnostic engine found a mover outside normal range. Same machinery as hover B.

Three states, not six. "Responding" doesn't need its own animation — text appearing is the animation. The badge is the future proactive entry point and it's driven by the same deterministic baseline/z-score code that answers "is this normal?" today, so V1 can ship it dark and flip it on later.

think: scale 1→1.18 sine, 1.1s · badge: 10px amber, top-right, only when |z| ≥ 2 · never a red badge

07What I'd lock for V1

StatePickWhy
CollapsedA · blob, with C's page-aware number as a later toggleShip the object first; the live number needs the SSE metric feed to be trustworthy
HoverB · one true thingFree — the diagnostic engine already computes it. Turns discoverability into a reason to open
EmptyB · today, then the box; with C's context barFacts invite questions; the context bar kills the "did you mean" round-trip
ConversationB · feed of cards with actionsEvery answer already carries dimensions, a DIAGNOSE path and provenance. Render them as buttons, not prose
ExpandedB · evidence panelTrust is the product. Source · period · rows · query is what makes a number believable to an owner
Forced statesall fourLadder, out-of-scope, picker, warning — each has a backend path already; skipping the UI for any of them degrades it to a paragraph

The one principle underneath all of it: every answer the backend produces is either a number with a source, a ranked list, a stepped sum, a warning, a question back, or a refusal. Six shapes. Give each a component, and Pulse feels like an instrument. Flatten them into chat bubbles, and it's ChatGPT in a box no matter how nice the blob is.
